# Smalltalk（说人话）

回答难以理解时，点击回答底部的“说人话”。T3 Code 会用选定的模型生成通俗解释，并保存在当前 thread 的 Smalltalk 中。每次生成会消耗该模型的额度。

右侧 Smalltalk 面板只列出已完成的解释，默认展开最新一条。点击历史项可以切换；顶部图标依次可以跳回原回答、复制、重新生成和删除。生成中的解释会直接显示在列表顶部，失败或取消的记录不会进入历史。关闭面板保留记录。

在右侧面板打开 Markdown 文件后，文件工具栏会显示“说人话”。点击后会用该文件的内容生成解释，并自动打开 Smalltalk 面板。文件来源的解释没有“跳转到原回答”。

生成过程中可以取消；Claude 和 Antigravity 会流式显示文字，Codex 在完成后显示完整解释。修改设置不会改变已有解释；点击“重新生成”才会使用当前模型和默认预设。

在 Settings → Threads → Smalltalk 中选择模型和默认 Prompt 预设。支持 Codex、Claude 和 Antigravity 的文本生成模型。内置“说人话”预设可以复制后编辑，也可以删除自己的预设。面板内不再提供预设选择。
