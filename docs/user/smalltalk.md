# Smalltalk（说人话）

回答难以理解时，点击回答底部的“说人话”。T3 Code 会用选定的模型生成通俗解释，并保存在当前 thread 的 Smalltalk 中。每次生成会消耗该模型的额度。

点击 thread 信息中 Highlights 下方的 Smalltalk，可以查看所有解释、复制结果或回到原回答。关闭面板保留记录；生成中可单独取消。移动端从 thread 顶部菜单打开 Smalltalk。

在 Settings → Threads → Smalltalk 中选择模型和默认 Prompt 预设。内置“说人话”预设可以复制后编辑，也可以删除自己的预设。修改设置不改变已有解释；点击“重新生成”才使用当前模型和所选预设。首版支持 Codex 和 Claude 的解释模型。
